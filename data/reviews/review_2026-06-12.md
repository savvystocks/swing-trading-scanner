## SYSTEM LEVEL

---

### PATTERN AUDIT

**VOL>OI on near-zero OI strikes: noise.** Both MU and SNDK triggered this on strikes with OI under 100. A 112x ratio on 73 OI contracts is arithmetic, not information. Any single institutional print on a virgin strike produces this number. The pattern is only meaningful when OI is in the thousands or the ratio is sustained across multiple strikes in the same expiry.

**Regime tailwind multiplier: unreliable and masking bad scores.** RISK_OFF_PRESSURE x1.15 is doing the work of elevating FITB (26→30) and SNDK (34→39) to pick-level. Meanwhile every put taken this week in this same regime is hitting the hard stop. The regime label is not filtering; it is manufacturing false confidence and pushing marginal scores above thresholds.

**Above-ask urgency: conditionally useful, currently being abused.** On MU the $8.2M above-ask on puts is legitimate size. On FITB it is $1M against $7M on the other side. The pattern needs a minimum absolute threshold and a check against the opposing side's urgency before it scores. As implemented it fires on scraps.

**FRESH FLOW bonus (+10):** Pure noise. First appearance in a scan means nothing. It should be zero points or negative pending a second confirmation.

**STABLE bonus (SNDK, ~33 for 2 scans):** A score that doesn't improve over two scans is not a conviction signal, it is stagnation. This should not add positive weight.

---

### BIGGEST FLAW

The system is classifying the macro regime as RISK_OFF_PRESSURE and applying a blanket 15% score uplift to puts, then using that uplift to push borderline names across pick thresholds. Five put positions hard-stopped today in the same regime. The regime signal is either lagging reality (the market is not moving with the regime label) or the multiplier is being applied before verifying that the individual name actually moves with the macro - financials, semis, and growth names do not all beta-match a generic risk-off regime equally.

**Concrete, testable fix:** Gate the regime multiplier on beta confirmation. Only apply the x1.15 RISK_OFF uplift to a put pick if the ticker's realized 10-day beta to SPX is above 1.0 AND the ticker's own price is below its 10-day moving average at scan time. This ensures the regime tailwind is corroborating name-level price action, not overriding it. This single change would have withheld the bonus from FITB (low beta, financial) and would require any semiconductor put to actually be in a downtrend before the multiplier fires. Run it against this week's resolved positions and check whether the five hard stops would have scored below pick threshold.
