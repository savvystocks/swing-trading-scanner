## What this settles (knowledge base #8 and #9)

1. **The wrapper never ate anything.** There was no stock-directional signal to eat: the full
   82-feature set carries ZERO information about which way the underlying moves next, at 1d or 3d.
   This generalizes the 07-25 event-level finding (raw signal 47–49%) to the model level and closes
   the last "hidden directional edge" escape route. The directional game is dead in every
   formulation this data supports.
2. **The Student's 0.72–0.73 is entirely option-space structure** — it ranks which CONTRACTS live
   or die (vol, liquidity, path behavior), knowing nothing about direction. Coherent with D3: both
   option labels (side and size) sit at ~0.72 because both are proxies for the same thing — how
   much the option moves, not which way the stock goes.
3. **Implication for Sunday**: the only games this pile can support are VOL-SIDE games. The one
   real skill in the data — identifying option-space movement — points at the structural frontier
   (premium/vol), not at any directional trade. That sharpens the premium-lane framing rather than
   changing it: cost-measurement first, and the pile's own skill is at least pointing at the same
   side of the market.

Day-clustered caveat (standing rule): 20 trading days underlie all of this; the AUC gaps are far too
large for day-clustering to reverse (0.73 vs 0.50 is not a clustering artifact), but absolute
confidence in any single number carries the ~2.2× n_eff shrink as always.
